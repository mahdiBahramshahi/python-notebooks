## 📚 درباره این مخزن

این مخزن شامل مجموعه‌ای از نوت‌بوک‌های آموزشی (Jupyter Notebooks) برای **دوره مقدماتی پایتون** است که توسط وبسایت **[زمین‌سنج](https://zaminsanj.ir)** تهیه شده است. 

در این دوره، مفاهیم پایه‌ای برنامه‌نویسی پایتون با استفاده از مثال‌های عملی و داده‌های واقعی در حوزه علوم زمین آموزش داده می‌شود.

## 🛠️ پیش‌نیازها

برای اجرای نوت‌بوک‌ها به موارد زیر نیاز دارید:

- Python 3.7+
- Jupyter Notebook یا JupyterLab
- کتابخانه‌های مورد نیاز:
  ```bash
  pip install pandas numpy matplotlib
  ```

## 🚀 نحوه استفاده

1. مخزن را کلون کنید:
   ```bash
   git clone <repository-url>
   cd <repository-folder>
   ```

2. وارد محیط ژوپیتر شوید:
   ```bash
   jupyter notebook
   ```

3. نوت‌بوک مورد نظر را انتخاب و اجرا کنید.
